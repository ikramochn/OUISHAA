OUSIHAA landing page

Before publishing:
1. Replace assets/scarf-placeholder.svg with your embroidered product photo and rename it scarf.jpg (or update the image path in index.html).
2. Replace assets/colors-placeholder.svg with your available-colors photo and rename it colors.jpg (or update the image path in index.html).
3. Open script.js and replace 213XXXXXXXXX with your WhatsApp number in international format, e.g. 2135XXXXXXXX.
4. Upload all files and folders while keeping the same structure to GitHub Pages.

The form opens WhatsApp with the customer's details, selected color, quantity, and calculated total. No order is stored on a server.
